# 公文写作 · gongwen-writing

面向中文公文及工作材料的 AI 写作技能：依据真实材料组织内容，在授权范围内借鉴范文、处理改稿反馈和维护写作方法。

**v0.4.0 · 首个公开试用版 · MIT**

## 能做什么

- 起草或实质修改工作总结、汇报、工作信息、讲话、方案等材料。
- 处理调研、政策阐释、实践分析等需要证据与论证的文章。
- 分析范文的结构、取材和论证，区分可借鉴的方法与不可移用的事实。
- 在用户授权后保存有价值的改稿反馈，区分临时要求、场景经验和明确的持续要求。

这是指令与参考文件组成的技能，需要支持技能的 AI 客户端执行。它不包含模型、私人资料库或 Word 排版程序，也不提供后台监听、模型训练或跨设备自动同步。

## 先用起来

**不连接资料库也能写作。** 提供用途、发言主体、篇幅和事实材料即可；只需提纲或局部修改时直接说明。

```text
请使用 gongwen-writing。根据下面的材料写一则工作动态，面向普通读者，
约 300 字。只在聊天中给稿，不保存反馈，不使用外部资料库。
事实材料：……
```

CLI 中可用 `$gongwen-writing` 明确调用；其他客户端使用其技能选择器。实际发现和调用情况以当前客户端为准。

## 安装到 Codex

### 方式一：让安装器处理

在提供 skill-installer 的 Codex 环境中提出：

```text
请用 skill-installer 安装 https://github.com/lizhixing0301-debug/gongwen-writing
仓库根目录中的技能。如已有同名版本，先说明差异，不覆盖我的个人版本。
```

### 方式二：手动安装（macOS / Linux）

需要 Git。在终端执行：

```sh
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/lizhixing0301-debug/gongwen-writing.git "$HOME/.agents/skills/gongwen-writing"
```

如果目标目录已经存在，停止安装，先备份并比较已有版本，不执行覆盖或删除。也可下载本项目发布包，将其中的 `gongwen-writing` 文件夹放入同一位置。

在技能列表中确认能够看到 `gongwen-writing`，再明确调用一次；未显示时重启客户端后复查。发现技能不等于已经完成写作或工具兼容性验证。同名个人版和公开版不要直接叠放到同一目录。

以上本地目录与调用方式依据 [OpenAI 技能文档](https://learn.chatgpt.com/docs/build-skills)，核对于 2026-10-21。本项目未逐一实测所有客户端；其他支持 `SKILL.md` 的客户端请按各自安装规则使用。

## 两种使用模式

| 模式 | 所需材料与工具 | 默认行为 |
| --- | --- | --- |
| 基础写作 | 当前对话及用户提供的可读材料 | 不查外部资料库，不保存反馈 |
| 私人资料库 | 用户明确指定的本地目录或云盘，以及相应读写工具 | 按授权读资料；保存与方法维护分别确认范围 |

配置资料库见 [资料库设置](references/library-setup.md)。本地目录和 Google Drive 是可选存储方式，均不随技能提供访问权限。没有连接或权限时如实说明，不用公开搜索替代私人文件读取。

**请把自己的稿件、范文、反馈和资料库配置放在本仓库以外的私人位置。** 公开版不包含作者的私人资料入口，也不要求把个人材料上传至本项目。

## 使用边界

范文中的数字、措施和成绩不能移成本单位事实；候选方法和一次稿件采用不能自动变成长期偏好。现行政策、法律及引语需要相应权威来源，缺依据时标明待核实。输出供起草和审阅使用，是否适合正式发出仍需结合具体业务要求核对。
