# 私人资料库设置

v0.4.0。资料库是可选能力。此文件是设置说明，不是现成连接，也不提供访问凭据。

## 默认状态

未指定资料库时，使用当前对话和附件完成写作或范文分析，跳过库内检索，不创建目录、不保存反馈。不要从历史聊天、作者配置或同名目录推测资料库位置。

连接只在当前环境实际具备工具和权限时成立。发现工具、读到元数据、读到正文、写入和回读是不同状态。

## 最小设置

从用户当前指令或用户明确指定的私人配置中取得下列信息；已有答案不重复问：

| 设置 | 含义 |
| --- | --- |
| 存储方式与位置 | 本地目录，或云盘服务及文件夹定位；不混用多个候选库 |
| 允许读取的范围 | 哪些范文、方法及反馈可用于当前任务，是否允许跨项目参考 |
| 反馈保存 | 默认关闭；启用时明确位置及可保存的内容范围 |
| 范文收录 | 与反馈保存分别授权，整篇原文须具有相应保存或共享授权 |
| 方法维护 | 是否可更新分析与指南；不包括改写原文或全局规则 |

可以直接在对话中说明这些设置，无须创建配置文件。若用户要求持久化设置，保存到其指定的私人位置，并遵守本环境的持久规则修改权限。不要将私人配置提交本公开仓库；本项目不提供配置自动加载程序。

示例是配置说明，不代表任何实际用户已授权：

```text
资料库采用我随后指定的本地目录。允许读取其中的范文和写法分析。
反馈保存关闭；如需收录新范文或更新方法，按我当次的明确要求处理。
不上传到云端，不扫描其他目录。
```

## 本地目录

1. 确认用户指定的目录、实际执行设备、可读范围和当前权限；设备不一致时不能把另一台机器的操作说成本地结果。不解析或跟随超出授权范围的符号链接，不为了查库遍历整个用户目录。
2. 只读相关文件，保持原文和分析的区分；不可读格式或正文缺失须说明，不假装全文读取。
3. 已获保存授权时读取目标当前状态，确认文件名与父目录。反馈默认位于已授权资料库下的“改稿反馈”子目录，确有合规记录且授权允许创建时才建立。
4. 原文、分析及方法文件优先沿用现有位置；空库且用户已授权首次收录时，仅创建承接本次原文与分析的必要文件。位置或创建范围不明时集中确认，不自行搭建整套库。
5. 新记录先查重并固定标识，不覆盖同名未知文件。更新既有文件前核对版本，遇到并发或内容变化先停止覆盖并重新读取；不能保证一致时交付拟更新内容或按授权追加关联修订。
6. 写后从实际目标路径重新读取，核对正文、来源、编号及保留项。写入指令未报错不等于内容正确。状态不明先查询原标识，不另建第二份。

## Google Drive 等云盘

使用当前已连接且获授权的服务工具；不预设固定函数名，不从公开网页搜索私人文件。按用户指定的文件夹定位，读取现有索引或列表并处理分页；不把同名文件夹当同一个，也不把部分结果当完整资料库。

只有用户的授权覆盖上传或共享范围时才写入。沿用实际存在的条目与编号，先读当前版本；权限拒绝不重试绕过，不改变分享设置。保存后从目标服务重新读取正文及位置，核对范围、内容和关联关系；超时先查原标识避免重复。

本地读取授权不包含云端上传，云盘可读不包含对外分享。只报告实际存储状态，不把一次上传解释为跨设备自动同步。

## 对所有存储方式都适用

[反馈判断](feedback-policy.md)、[反馈卡](feedback-record.md) 和 [范文学习](example-learning.md) 中的“资料库”“回读”均指这里确认的实际位置和工具。“共享”只用于确有跨人、跨项目或云端传输的场景；仅本地保存按原本地范围授权。

当前任务说“只讨论”“不记录”“不写文件”时，不保存原文、摘要或推断。仅提供链接或附件不等于允许收录；不通过脱敏、归纳或另存位置绕过限制。测试只在明确授权的隔离测试位置运行，不写入真实反馈库。
